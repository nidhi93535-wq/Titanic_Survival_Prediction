# Titanic Survival Prediction Using Linear Regression and Decision Tree

## Project Overview

This project demonstrates the application of supervised machine learning algorithms on the Titanic dataset. The objective is to predict passenger survival based on various features such as passenger class, age, gender, fare, family size, and other engineered features.

The project uses a preprocessed Titanic dataset obtained after performing data cleaning and feature engineering. Two machine learning models were implemented and evaluated:

1. Linear Regression
2. Decision Tree Classifier

The performance of these models was analyzed using appropriate evaluation metrics and visualizations.

## Objectives

* Load and utilize the cleaned Titanic dataset.
* Perform data preprocessing for machine learning.
* Split the dataset into training and testing sets.
* Train a Linear Regression model.
* Train a Decision Tree Classifier.
* Evaluate model performance using suitable metrics.
* Visualize model outputs and compare results.

## Dataset Description

The Titanic dataset contains information about passengers aboard the RMS Titanic. The dataset includes demographic and travel-related details that can be used to determine survival outcomes.

### Features Used

* PassengerId
* Pclass
* Sex
* Age
* SibSp
* Parch
* Fare
* Embarked
* Title (engineered feature)
* AgeGroup (engineered feature)
* FamilySize (engineered feature)

### Target Variable

* Survived

  * 0 = Did Not Survive
  * 1 = Survived


## Data Preprocessing

The dataset used in this project was obtained after completing Task 2 (Data Cleaning and Feature Engineering).

The following preprocessing steps were already applied:

### Data Cleaning

* Missing values in Age were handled using median imputation.
* Missing values in Embarked were filled using the mode.
* The Cabin column was removed due to a large number of missing values.
* Duplicate records were removed.

### Feature Engineering

* Passenger titles were extracted from names.
* Age groups were created using age ranges.
* Family size was calculated using SibSp and Parch.
* Categorical variables were converted into numerical form.
* Numerical features were scaled for better model performance.


## Machine Learning Models

### 1. Linear Regression

Linear Regression is a supervised learning algorithm used to model the relationship between independent variables and a target variable.

In this project, Linear Regression was applied to estimate survival outcomes based on passenger attributes.

#### Evaluation Metrics

* Mean Squared Error (MSE)
* R² Score

### 2. Decision Tree Classifier

Decision Tree is a supervised classification algorithm that makes predictions by learning decision rules from data features.

The model recursively splits the dataset into smaller subsets until it reaches a prediction.

#### Evaluation Metric

* Accuracy Score
